# もこもこおみせタウン — にこにこサロン

Windows PCで遊べる、2店舗の小さな試作品です。今回の更新は絵本版1.4（こむぎベーカリー）です。春の広場からサロンとパン屋を選べます。パン屋では生地・具材・焼き加減を選んでパンを焼きます。旧版の進み具合、おめかしアルバム、前掛けのないキャラクター、中央のリボンを引き継いでいます。
時間制限はなく、左クリックだけで遊べます。

## すぐ遊ぶ

ローカルでは `MokomokoSalon-Windows/NikonikoSalon.exe` を起動してください。元のフォルダーも1.4版に更新済みです。`MokomokoSalon-Windows-1.4` にも同じ版を残しています。

1. `MokomokoSalon-Storybook-Windows.zip` を右クリックして「すべて展開」します。
2. 展開した `MokomokoSalon-Windows` フォルダの **`NikonikoSalon.exe`** をダブルクリックします。
3. 初めて遊ぶ場合は「はじめから」、保存済みの進み具合を引き継ぐ場合は「つづきから」を選びます。

Windows版にはゲーム本体が含まれています。Godotのインストール、アカウント、インターネット接続は不要です。
ZIP内から直接実行せず、展開してから起動してください。
ファイルはローカル用に作成したもので、外部サイトには公開していません。

## 遊び方

1. 広場で「にこにこサロンへ」をクリックし、受付で「おねがい」を読んで「おめかしを はじめる」を選びます。
2. ①髪かざりの形、②髪かざりの色、③首のリボンの色を選びます。
3. 左側のお客さまに、選んだおしゃれがすぐ反映されます。完成前なら何度でも選び直せます。
4. 3つ選ぶと「これで できあがり！」を押せます。
5. 得点と満足度を見て、「つぎのお客さまへ」をクリックします。
6. 3人接客すると、その日の合計と最高得点が出ます。「つぎの日へ」で翌日の広場へ戻り、サロンに入ると続けて遊べます。

| 操作 | 内容 |
| --- | --- |
| マウスの左クリック | ボタン、形、色を選ぶ |
| 右上「音：オン／オフ」 | 効果音を切り替える |
| サロン上部「広場へ」 | 接客途中の状態を保って広場へ戻る |
| 「タイトルへ」または Esc | 保存してタイトルへ戻る |
| タイトル「つづきから」 | 保存した場面から再開する |
| タイトル「おしまい」またはウィンドウの × | 保存して終了する |

確認画面やアルバムを開いているときの Esc は、その画面を閉じます。
「はじめから」は既存の進み具合とアルバムを置き換えるため、セーブがある場合だけゲーム内で確認します。

## こむぎベーカリー（1.4で追加）

1. 広場の中央にある「こむぎベーカリーへ」を選びます。
2. お客さまの注文を読み、「パンを つくる」を押します。
3. 生地（ミルク／ココア／全粒粉）、具材（チョコ／いちご／チーズ）、焼き加減（ふんわり／こんがり／カリッと）を選びます。組み合わせは27通りで、左のパンに見た目が反映されます。
4. 3つ選ぶと「オーブンで 焼く！」を押せます。約3秒の焼き上がり演出のあと、自動で採点します。タイミング操作は不要です。
5. 注文と生地が合うと40点、具材と焼き加減は各30点。違うパンを作っても完成し、次のお客さまへ進めます。
6. パン屋も1日3人です。「つぎの日へ」で広場に戻ります。

サロンとパン屋の接客人数・日数・得点・最高点・選択途中の状態は、それぞれ独立して保存します。
パン作りの途中でサロンに移っても、両方のお店を続きから遊べます。
焼いている途中で広場やタイトルへ戻ると演出を一時停止し、再入店時には約3秒の演出から再開します。結果の再開で二重に採点することはありません。
アルバムを開いている間も焼き上がり演出を一時停止します。おめかしアルバムはサロン専用です。
「はじめから」を確定すると、両方のお店とアルバムをリセットします。

## 町の広場（1.3で追加）

「はじめから」で始めると、春の広場が開きます。
左の「にこにこサロンへ」、中央の「こむぎベーカリーへ」で接客を始められます。
サロンの上部にある「広場へ」は、受付・選択途中・結果のどの場面でも使えます。
再びサロンに入ると、同じお客さま・選択・得点のまま再開します。
1日3人の接客後に「つぎの日へ」を押すと、翌日の広場に戻ります。

広場からアルバム、音の切り替え、タイトルへ戻る操作もできます。
「これまでのおもてなし」は、サロンとパン屋の累計得点の合計です。
「こもれび雑貨店」は準備中の案内を見ることができ、購入やポイント消費はまだありません。
今後、ポイントで小物を買える機能を追加するための入口として配置しています。

広場にいることも自動保存します。
1.2.1以前のセーブには場所の情報がないため、従来どおり保存済みのサロン場面から再開します。
旧セーブでもサロンの「広場へ」から新しい広場へ移動できます。

## おめかしアルバム（1.2で追加）

- 「これで できあがり！」で採点すると、完成したおしゃれを1枚だけ自動記録します。0点でも残ります。
- タイトル・広場・受付・おめかし・結果画面の上部にある「おめかしアルバム」から開けます。
- お客さまの姿、実際に選んだ髪かざりと色、接客した日・順番、得点を見返せます。
- 新しい順に表示します。「前の思い出」「新しい思い出」でページを送り、「とじる」または Esc で元の画面へ戻ります。
- 最新120枚を保存します。121枚目からは一番古い思い出を入れ替えます。合計点・接客人数には影響しません。
- 接客途中に開いても、選びかけのおしゃれや進行は変わりません。
- 1.1以前のセーブはそのまま再開できます。以前の完成衣装は履歴がないため、更新後に完成した分から記録します。旧版で採点済みの結果を再開しても追加記録・再採点はしません。
- アルバムは進行と同じセーブに保存され、バックアップからも一緒に復旧します。「はじめから」を確定すると両方とも初期化します。

## 得点・満足度

- 髪かざりの形：40点
- 髪かざりの色：30点
- 首のリボンの色：30点
- お客さま1人につき最大100点。1日3人で最大300点です。
- 満足度は、100点で星5、70点以上で星4、40点以上で星3、1～39点で星2、0点で星1です。
- 結果の「○」は希望どおり、「△」は希望と違った項目です。表示される品名・色名は、お客さまの希望です。

間違えてもゲームオーバーになりません。
得点を確定したお客さまへの採点は1回だけです。
合計点、おもてなし人数、100点の回数、1日の最高点が記録されます。

## 保存と再開

広場と各店の移動、選択、オーブン開始、採点、次のお客への移動で自動保存します。
「タイトルへ」と終了時にも保存します。
選びかけの状態も再開でき、採点後に再開しても点数は二重に加算されません。

通常の保存場所：

```text
%APPDATA%\MokomokoSalon\salon_save.json
```

エクスプローラーのアドレス欄に `%APPDATA%\MokomokoSalon` と入力すると開けます。
保存成功時に、前回の正常な内容を `salon_save.json.bak` に残します。
本体が読めない場合はバックアップを読み込みます。その場合、最後の操作より1回前に戻ることがあります。
両方とも読めない場合は、通知を表示して「はじめから」で遊べます。
保存できない場合は画面下に通知し、未保存のままタイトルに戻る・終了する前に確認します。

セーブは1つです。PCの同じWindowsユーザーで、複数のゲームウィンドウを同時に起動しないでください。
プロジェクトから遊ぶ場合とWindows実行ファイルは、通常、同じセーブを使います。

## Godotで開く・編集する

推奨・検証済み環境は **Godot 4.5.1 Standard（GDScript版）** です。
Godot 3.xでは動きません。.NET版は不要です。

1. [Godot公式の4.5.1配布ページ](https://godotengine.org/download/archive/4.5.1-stable/)からWindows版を入手します。
2. `MokomokoSalon-Storybook-GodotProject.zip` を展開します。
3. Godotのプロジェクトマネージャーで「インポート」を選び、`MokomokoSalon/project.godot` を指定します。
4. フォントなどの読み込みが終わったら、右上の再生ボタンまたは **F5** でゲーム全体を起動します。

フォント、イラスト、効果音はプロジェクトに含まれるか、実行時に生成されます。
プラグインや追加パッケージは不要です。

### プロジェクトの構成

```text
project.godot             プロジェクト設定
main.tscn                起動シーン
scripts/main.gd          日本語UI・画面遷移・マウス操作・アルバム閲覧
scripts/bakery_model.gd  パン屋の依頼・調理状態・採点・検証
scripts/bakery_view.gd   パン屋の日本語UI
scripts/bakery_art.gd    店内・パン・具材・オーブンの描画
scripts/town_view.gd     広場の背景・お店の配置・累計得点の表示
scripts/salon_model.gd   お客、依頼、採点、進行、アルバム記録、データ検証
scripts/save_store.gd    保存とバックアップからの復旧
scripts/salon_art.gd     絵本風背景・動物画像と付け替え小物の描画
scripts/salon_audio.gd   オリジナル効果音の生成
assets/fonts/            日本語フォントとライセンス
assets/icon.png          うさぎ「もも」のゲーム用アイコン
assets/icon.ico          Windows実行ファイル用アイコン
assets/favicon.*         ブラウザー用ファビコン
tests/                   ルール検証、クリック操作検証、検証報告
screenshots/             検証時の実画面
licenses/                Godot等の使用許諾文
export_presets.cfg       Windowsへの書き出し設定
```

お客さまや依頼は `scripts/salon_model.gd` の `CUSTOMERS` と `ORDERS` にまとめています。
見た目は `scripts/salon_art.gd`、色と画面配置は `scripts/main.gd` で変更できます。

### Windows版を書き出し直す

Godotの「エディター → エクスポートテンプレートの管理」で、4.5.1のテンプレートを入れます。
「プロジェクト → エクスポート」の `Windows Desktop` を選び、実行ファイルを書き出します。
ゲームデータはexeへ埋め込む設定です。
再配布するときは `LICENSE.txt`、`ASSETS.md` と `licenses`、フォントの `OFL.txt` も添付してください。

詳しい対象、結果、制約は `tests/TEST_REPORT.md` を参照してください。

再実行する例（PowerShell。Godotの場所は自分の環境に合わせて変更します）：

```powershell

& 'C:\Godot\Godot_v4.5.1-stable_win64_console.exe' --headless --path . --script res://tests/test_rules.gd
```

`MokomokoSalon` フォルダで実行してください。
テストは本番セーブを使わず、専用の `tests/_runtime` と `user://qa` を使います。
環境変数 `MOKOMOKO_QA_DIR` を指定すると、UIテストの保存先をそのフォルダへ変更できます。UIテスト画像も指定先の `screenshots` に保存します。
今回の検証では `tests/_runtime/bakery_ui` と `tests/_runtime/bakery_release_ui` を使いました。
UIテストはゲーム画面を開き、自動で閉じます。検証フォルダー内のスクリーンショットも更新します。

### セーブ互換性の実装

保存場所と `version: 1`、既存11フィールドの意味を維持しています。
任意フィールド `album` に、接客番号（0起点）・選択3項目・得点を記録します。
`album` がない旧セーブは空のアルバムとして復元します。
任意フィールド `location` は `town`（広場）／`salon`（サロン）／`bakery`（パン屋）のいずれかを保存します。
場所は受付・選択・結果を表す `phase` と独立しており、広場へ出ても接客状態は維持します。
`location` がない旧セーブは `salon` として復元します。
任意フィールド `bakery` にパン屋の状態を保存します。ない旧セーブではパン屋だけを初期化します。既存の `total` 等はサロン専用の意味を維持し、広場でのみ両店を合算します。
同じセーブ内で進行とアルバムを一緒に保存するため、採点後の再開でも履歴が重複しません。
表示画像は既存の背景・動物・小物から描画し直します。画像ファイルをセーブへ書き込む方式ではありません。

買い物機能の今後の設計案は `docs/SHOPPING_PLAN.md` にまとめています。累計得点と消費可能な残高を分け、購入時に残高と持ち物を一緒に保存する方針です。

## 動作環境と今回の範囲

- Windows 10/11、64bit。描画はGodotのCompatibility（OpenGL 3.3）です。
- 基準画面1280×800、最小960×600。縦横比を保って拡大縮小します。
- 6人のお客さま、動物6種、サロンの依頼12通り、形3種、色4種です。パン屋は依頼9通り、生地・具材・焼き加減が各3種です。
- 依頼と来店順は決まった順で繰り返します。1日3人を何日でも続けられます。
- 春の広場とサロン・パン屋の2店舗を行き来できます。雑貨店は準備中です。買い物、髪を切る操作、物語の進行は含みません。
- 音は短い効果音のみです。BGMと音声はありません。
- 共有いただいた「もこもこおみせタウン 春の広場」を参照し、絵本風の背景と動物6種を画像生成して組み込みました。キャラクターは参照絵に合わせた新規描画です。
- 別PC・異なるGPUでの動作、長期間のプレイ、停電やOS強制終了中の保存は未検証です。

## アイコン

うさぎ「もも」に合わせたアイコンを、Godotのプロジェクト・ゲームウィンドウ・Windows実行ファイルに設定しています。
